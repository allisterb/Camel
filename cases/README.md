# About

This directory contains case directories for the SRL-2018 and SRL-2015 scenarios investigated by Claude using Camel. Each directory has the investigation reports generated and audit and other logs.
The report.html file in each directory is an interactive HTML viewer for viewing all the case data in one place.

The full set of 8 cases investigated by Claude/Camel can be found here: https://drive.google.com/drive/folders/1whw7GwrZUxADTsy1f-LCV2jN-Q-fpVNp?usp=sharing
