# About

This directory contains case directories for the SRL-2018 scenario investigated by Claude using Camel. Each directory has the investigation reports generated and audit and other logs.
The logs dir has the audit and other logs for the case. The reports dir has Markdown and interactive reports.

The full set of 8 cases investigated by Claude/Camel can be found here: https://drive.google.com/drive/folders/1whw7GwrZUxADTsy1f-LCV2jN-Q-fpVNp?usp=sharing
