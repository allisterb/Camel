# About

Camel is designed to 'lower' DFIR analysis by AI from thinking using natural language skills over low-level tools to thinking using code generation over specialized workflows and machine learning routines
that codifies DFIR analyst knowledge
. This lowering
significantly reduces the time AI agents spend

# Advantages

* Deterministic output: High-level code operations are repeatable at a high level allowing the sequence of forensic tool commands to be replayed
* Parallel execution: Workflow steps without dependenices can execute in parallel, significantly reducing the run times for analysis
